## What this site is

The Tidy DS Toolbox is a Figma plugin.
It holds a set of modules, and each module does one job on a design system file.

This site has one page for each module.
A module page tells you what the module does, when to use it, and how to run it, step by step.

## Start here

<CardGrid>
	<Card title="Install it, in two steps" icon="rocket">
		[Install the Figma plugin](/setup/install-plugin/) to get the panel.
		Then [connect it to Claude](/setup/connect-claude/) for the modules you

	</Card>
	<Card title="Then select a module" icon="open-book">

## Two ways to run a module

<CardGrid>
	<Card title="From the panel" icon="figma">
		Most modules are buttons in the Figma panel.
		The panel groups them under **Stable**, **Beta** and **Alpha**, and the
		sidebar here uses the same groups.
		An alpha module works, and its result can change between releases.
	</Card>
	<Card title="From Claude" icon="seti:todo">
		Seven modules take a slash command, such as `/tidy-ds:tidy-qa`.
		[Slash commands](/commands/) lists every one of them.
		Where a module works both ways, its page says which way gives which
		result, because they are not always the same.
	</Card>
</CardGrid>
