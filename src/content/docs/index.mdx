## What this site is

The Tidy DS Toolbox is a Figma plugin.
It holds a set of modules, and each module does one job on a design system file.

This site has one page for each module.
A module page tells you what the module does, when to use it, and how to run it, step by step.

<CardGrid>
	<Card title="Start with a module" icon="open-book">
		Select a module in the sidebar.
		The sidebar follows the plugin panel, so a module is in the same group here
		as it is in the panel.
	</Card>
	<Card title="Maturity groups" icon="approve-check">
		The panel groups modules under **Stable**, **Beta** and **Alpha**.
		An alpha module works, but its result can change between releases.
	</Card>
	<Card title="Two ways to run a module" icon="setting">

		Some modules can also be driven from Claude, and the result is not always
		the same. The module page says which way gives which result.
	</Card>
